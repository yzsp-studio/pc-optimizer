Cleans up disk junk and frees space, tackles sluggishness and slow boot times, tunes Windows/macOS performance, lifts game frame rates and generates safe cleanup scripts. Step zero of the core flow is deciding whether it is running on a local machine or a cloud sandbox; step one identifies the operating system, because that decides everything downstream. Use it when someone mentions a full C: drive, low disk space, dropped frames or slow performance.

### ✨ What it does

- Step zero: decide whether it runs on a local machine or a cloud sandbox
- Step one: identify the OS, which determines the entire downstream flow
- Clean up disk junk, free space and resolve a full C: drive
- Diagnose stutter and slow startup, then give a handling path
- Tune Windows/macOS performance and raise game frame rates
- Generate safe cleanup scripts you can review before running
